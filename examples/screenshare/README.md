# 旧画面共有プラグイン（互換試験用）

画面共有・カメラ共有は、本体の通話機能へ移しました。現在の実装は [`app/src/lib/call/screen/`](../../app/src/lib/call/screen/) と本体の Svelte コンポーネントにあります。設計は [標準の画面共有](../../docs/design/call-screen.md) を参照してください。

このフォルダの v0.5.7 は、旧クライアント向けの最終配布物と、既存の振る舞いを確認する試験用に保持します。新しい本体はこのプラグインを読み込みません。標準機能をここへ実装したり、このプラグインを更新して配布したりしないでください。
