## Default Permission

画面のキャプチャ、自分の画面の静止画、ピクチャーインピクチャーを許可する

#### This default permission set includes the following:

- `allow-start-capture`
- `allow-update-capture`
- `allow-stop-capture`
- `allow-snapshot`
- `allow-enter-pip`
- `allow-register-listener`
- `allow-remove-listener`
