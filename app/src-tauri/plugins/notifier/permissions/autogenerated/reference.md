## Default Permission

通知用の常駐サービスの操作を許可する

#### This default permission set includes the following:

- `allow-start`
- `allow-stop`
- `allow-start-call`
- `allow-stop-call`
- `allow-native-call-start`
- `allow-native-call-stop`
- `allow-native-call-snapshot`
- `allow-native-call-control`
- `allow-native-call-kick`
- `allow-native-call-emit`
- `allow-take-call-actions`
- `allow-list-audio-outputs`
- `allow-set-audio-output`
- `allow-take-shared`
- `allow-status`
- `allow-request-permission`
- `allow-open-battery-settings`
- `allow-set-orientation`
- `allow-set-keep-web-view`
- `allow-log-call`
- `allow-diag-log`
- `allow-diag-read`
- `allow-diag-clear`
- `allow-diag-share`
- `allow-vibrate`
- `allow-take-launch-target`
- `allow-register-listener`
- `allow-remove-listener`
- `allow-recent-images`
- `allow-request-recent-images-permission`
- `allow-read-image`
- `allow-clipboard-image`
- `allow-clipboard-peek`
- `allow-clipboard-text`
