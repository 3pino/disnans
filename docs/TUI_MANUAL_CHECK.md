# TUI 実機確認メモ（P0）

`disnans tui` を目で確かめるための手順です。自動テストでは見た目・実端末の挙動を確認していません。

## 起動

```sh
# 開発サーバー（一時データ）
DISNANS_DEV=1 DISNANS_BIND=127.0.0.1:8080 DISNANS_DATA_DIR=$(mktemp -d) disnans-server
disnans --server http://127.0.0.1:8080 --dev-user alice tui

# 通常（接続先を設定済み）
disnans config set-server 100.x.y.z:8080
disnans tui
```

端末（TTY）以外では起動せず終了コード 2 になります。

## キー

| 操作 | キー |
| --- | --- |
| 送信 | サーバー設定の送信キー（既定 Ctrl+Enter / Alt+Enter）、常に使える Ctrl+S |
| 改行 | 既定 Enter / Shift+Enter、常に使える Ctrl+J |
| 履歴スクロール | PgUp / PgDn、Alt+↑ / Alt+↓、Ctrl+Home（最古）/ Ctrl+End（最新） |
| 履歴の再取得 | Ctrl+R |
| 終了 | Ctrl+Q または Ctrl+C（入力中の本文は下書きに保存） |

入力欄の下の案内に、その端末で使えるキーだけが出ます。

## 確認項目

- [ ] 履歴: 起動後に古い順で表示され、最新に追従する。時刻がローカル時間。表示名が出る。
- [ ] 上へスクロールして先頭近くで古い履歴が追加される。読んでいる間は新着で位置が動かない。
- [ ] 送信: 送信キーで投稿でき、入力欄が空になる。サーバー側の Enter 設定を GUI で変えると反映される。
- [ ] 別端末から受信: GUI や `disnans send` の投稿・編集・削除が反映される。
- [ ] 切断復帰: サーバーを止めると「切断・再接続中」、再開すると「接続済み」に戻り、切断中の投稿が補われる。
- [ ] 下書き保持: 入力途中で Ctrl+Q → 再起動で復元される。送信確定後は消える。GUI と同じ下書きを共有する。
- [ ] Unknown 表示: 送信直後にサーバーを止める等で「送信結果が不明」と client_id が出て、自動再送されない。もう一度送信キーで確認文が出て、さらに押すと送る。
- [ ] 小さい端末: 20×8 未満で「画面が小さすぎます」、広げると復帰する。リサイズで崩れない。
- [ ] 日本語・絵文字: 全角・絵文字が折り返しやカーソル位置でずれない。制御文字・ESC を含む投稿が `\u{..}` で見える。
- [ ] 終了後に端末（カーソル・入力エコー・通常画面）が元に戻っている。`kill -TERM` でも戻る。
- [ ] Windows Terminal / PowerShell: 起動・日本語入力・Shift/Ctrl+Enter。

## 既知の制限

- 既読の更新、返信、添付、リアクション操作は未対応（表示のみ）。
- Shift+Enter / Ctrl+Enter を区別できるのは kitty キーボードプロトコル対応端末と Windows コンソール。他は Alt+Enter / Ctrl+S / Ctrl+J を使う。
- 絵文字や結合文字は端末ごとに幅の扱いが違い、ずれることがある。
- panic で落ちた場合、端末は復元されるが 0.5 秒以内の未保存の下書きは失われる。
- マウスは使わない。
