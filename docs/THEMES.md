# テーマの作り方

disnans のテーマは、Obsidian のテーマに近い仕組みです。**CSS のファイルを1つ書くだけ**で、本体の色や角の丸みを変えられます。
JS は使いません。配り方はプラグインと同じで、「みんなに配布」も「自分だけに配布」もできます。

- 設計: テーマの配り方はプラグインと同じ（[`PLUGINS.md`](PLUGINS.md)）。上書きできる変数は、このファイルの一覧が正
- 実例: [`examples/theme-sakura/`](../examples/theme-sakura/)（桜色のテーマ）
- 配布の API: [`API.md`](API.md) の「プラグイン」

## 仕組み

```
theme-sakura/
├── manifest.json   # "type": "theme" を書く
├── theme.css       # 必須
└── icon.svg        # 任意（一覧のアイコン）
```

- テーマは **1つだけ** 選べます（**設定 → 外観 → カスタムテーマ**）。選んだものは同じアカウントのデバイスで共有されます。選ばなければ本体の見た目のままです
- 選ぶと、`theme.css` を `<style>` として **本体の CSS（`app.css` と、それが読み込む `styles/`）より後ろ** に入れます。外すと取り除きます
- ライト / ダーク / 自動の切り替え（設定 → 外観 → テーマ）はそのまま使えます。テーマはライトとダークの両方の値を書きます
- 開発用フォルダ（PC 版）に置いたテーマは、保存すると自動で読み込み直します（ホットリロード）
- 選んだテーマの CSS はデバイスに覚えておき、次に起動したときはサーバーの応答を待たずに適用します

## 5分で動かす

1. PC 版の **設定 → プラグイン → 開発用フォルダ** を決めます（プラグインと同じフォルダです）
2. その中に `theme-sakura/` のようなフォルダを作り、`manifest.json` と `theme.css` を置きます（`examples/theme-sakura/` をコピーしてもかまいません）
3. **設定 → 外観 → カスタムテーマ** に出てくるので、トグルをオンにします
4. `theme.css` を書き換えて保存すると、すぐに反映されます
5. 出来上がったら、同じ一覧の **[配布]** を押し、「みんなに配布」か「自分だけに配布」を選びます

ブラウザー版（開発用）では、**設定 → プラグイン → ファイルを選んで配布** で `manifest.json` と `theme.css` をまとめて選びます。

## manifest.json

プラグインの manifest と同じ形で、`"type": "theme"` を足します。

```json
{
  "id": "theme-sakura",
  "type": "theme",
  "name": "さくら",
  "version": "1.0.0",
  "description": "桜色のアクセントと、少し暖かいグレー",
  "author": "sanpino",
  "icon": "flower-2"
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | ○ | 英小文字・数字・ハイフン（2〜32文字）。**プラグインとテーマを通して**サーバー内で一意。`theme-` で始めるのがおすすめ |
| `type` | ○ | `"theme"`（省略するとプラグインとして扱う） |
| `name` | ○ | 表示名 |
| `version` | ○ | 更新のときに上げる |
| `description` / `author` | | 一覧に出る説明・作った人 |
| `icon` | | 一覧のアイコン。Lucide のアイコン名（省略すると `palette`）。`icon.svg` を置けばそちらが優先 |

- 配布できるのは `manifest.json`・`theme.css`・`icon.svg`（任意）だけです。`main.js` や `styles.css` は置けません（サーバーが断ります）
- 合計 5 MB まで。`minApiVersion` はテーマには関係ありません

## theme.css の書き方

本体の色や大きさは、`:root` の CSS 変数（トークン）になっています（[`@3pino/design-system` の `tokens.css`](https://github.com/3pino/design-system/blob/master/src/tokens.css)）。
テーマは基本的に **この変数を上書きするだけ** にします。ボタンや入力欄など、本体の部品はすべて変数から色を取るので、変数を変えれば全体が変わります。

基本の色相・彩度は `--hue` / `--chroma`、アクセントの色相は `--hue-accent` で指定できます。`--bg` などの個別色だけを変える旧テーマは、追加されたフォーカス枠・入力背景・幕などに本体の色相が残ることがあります。これらにもテーマの色を使うには、パレットも上書きしてください。`theme-sakura` v1.0.1 でこの対応を加えています（色・描画の最終確認は利用者が行います）。

本体はライト・ダークを次の3つのセレクターで書いています。テーマも**同じ3つ**を書きます（同じ詳細度なので、後ろにあるテーマが勝ちます）。

```css
/* ライト（既定） */
:root {
  --accent: oklch(0.52 0.15 355);
}

/* ダーク（設定が「自動」で、デバイスがダークのとき） */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme='light']) {
    --accent: oklch(0.8 0.1 355);
  }
}

/* ダーク（設定で「ダーク」を選んだとき）。上と同じ値を書く */
:root[data-theme='dark'] {
  --accent: oklch(0.8 0.1 355);
}
```

- `:root` だけを書くと、ダークのときは本体のダークの値（詳細度が高い）が勝ってしまいます。ダークも変えるなら、下の2つも書いてください
- 書かなかった変数は本体の値のままです。アクセント色だけ変える、角の丸みだけ変える、といった小さなテーマも作れます
- `--accent-soft` などの「派生」の変数は、元の変数（`--accent` など）から自動で計算されます。元だけ変えれば十分です
- 色は `oklch()` がおすすめです（本体もそうしています。明度 L だけ変えればライト・ダークを作りやすい）。
  本体の決まりは、中立色が `oklch(L 0.015 248)`、意味を持つ色はライトで L 0.45 前後・ダークで L 0.74 前後です
- 文字と背景のコントラストに気をつけてください。目安は `--text` と `--bg` が 7 : 1 以上、`--text-muted` と `--bg` が 4.5 : 1 以上です

### 変数より細かく変えたいとき

テーマは自分のデバイス（と、選んだ人のデバイス）にしか効かないので、プラグインと違って本体のセレクター（`body` や `.btn` など）を書き換えてもかまいません。
ただし、**本体のクラス名や DOM は予告なく変わる**ことがあります。変数で済むことは変数で書いてください。
本体の共通クラスの一覧は [PLUGIN_UI.md の「CSS クラス」](PLUGIN_UI.md#css-クラス) にあります。

```css
/* 例: 本文を少し大きく */
body {
  font-size: 16px;
}
```

## CSS 変数の一覧

### 色（ライト・ダークで値が変わる）

| 変数 | 用途 | ライト | ダーク |
|---|---|---|---|
| `--bg` | いちばん下の背景 | `oklch(0.97 0.015 248)` | `oklch(0.17 0.015 248)` |
| `--surface` | 一段浮いた面（サイドバー、カード、メニュー） | `oklch(0.94 0.015 248)` | `oklch(0.21 0.015 248)` |
| `--surface-2` | 二段浮いた面（ボタン、入力欄の背景など） | `oklch(0.9 0.015 248)` | `oklch(0.26 0.015 248)` |
| `--border` | 線 | `oklch(0.84 0.015 248)` | `oklch(0.32 0.015 248)` |
| `--text-muted` | 控えめな文字 | `oklch(0.48 0.015 248)` | `oklch(0.7 0.015 248)` |
| `--text` | 文字 | `oklch(0.22 0.015 248)` | `oklch(0.93 0.015 248)` |
| `--accent` | リンク、送信ボタン、選択状態 | `oklch(0.45 0.11 248)` | `oklch(0.74 0.13 248)` |
| `--mention` | 自分宛てのメンションの強調 | `oklch(0.45 0.09 75)` | `oklch(0.74 0.12 75)` |
| `--danger` | エラー、削除 | `oklch(0.45 0.15 25)` | `oklch(0.74 0.15 25)` |
| `--success` | 成功、オンライン表示 | `oklch(0.45 0.1 155)` | `oklch(0.74 0.12 155)` |
| `--warning` | 警告 | `oklch(0.45 0.09 85)` | `oklch(0.74 0.13 85)` |
| `--avatar-l` | 画像のないアバターの背景の明度（色相は人ごと） | `0.45` | `0.74` |
| `--shadow` | 浮いたもの（メニュー、ダイアログ）の影 | 薄い影 | 濃い影 |

`color-scheme`（スクロールバーやフォームの既定の色）も、本体が `:root` でライト・ダークを切り替えています。テーマで変える必要はありません。

### 派生（元の変数から自動で決まる）

| 変数 | 既定の値 |
|---|---|
| `--on-accent` | `var(--bg)`（アクセント色の上の文字） |
| `--accent-soft` | `--accent` を 14% にした薄い背景 |
| `--mention-soft` | `--mention` を 16% にした薄い背景 |
| `--danger-soft` | `--danger` を 14% にした薄い背景 |
| `--hover` | `--surface-2` を 60% にしたホバーの背景 |

上書きしてもかまいません（例: アクセント色が明るすぎて `--bg` の文字が読みにくいなら、`--on-accent` を変える）。

### 形・大きさ・フォント（ライト・ダーク共通）

| 変数 | 用途 | 既定 |
|---|---|---|
| `--radius` | 角の丸み（カード、ダイアログ、メニュー） | `10px` |
| `--radius-sm` | 小さな角の丸み（ボタン、入力欄、タグ） | `6px` |
| `--radius-xs` / `--radius-lg` / `--radius-xl` / `--radius-pill` | さらに小さい / 大きい（モーダル）/ 吹き出し / 完全な丸 | `4px` / `14px` / `16px` / `999px` |
| `--fs-xs` … `--fs-2xl` | 文字サイズ（`xs` 10 / `sm` 12 / `base` 14 / `body` 15 / `lg` 16 / `xl` 20 / `2xl` 24 px） | 左のとおり |
| `--fw-medium` / `--fw-semibold` / `--fw-bold` | 文字の太さ | `500` / `600` / `700` |
| `--lh-tight` / `--lh-body` | 行の高さ | `1.4` / `1.55` |
| `--space-1` … `--space-8` | 余白（gap・padding・margin）。2 / 4 / 6 / 8 / 10 / 12 / 16 / 24 px | 左のとおり |
| `--font` | 本文のフォント | システムのフォント（日本語は Hiragino / Noto Sans JP / Yu Gothic UI など） |
| `--serif` | 明朝・セリフ体のフォント（本体では使っていない。流用先用） | `ui-serif` ほか |
| `--mono` | 等幅のフォント（コード） | `ui-monospace` ほか |
| `--nav-side-w` | 広い画面で左に縦に並べるナビゲーションバーの幅 | `76px` |
| `--panel-w` | PC 版の右側のパネルの幅 | `420px` |

## 配布と、選択

配布・更新・削除はプラグインと同じです（→ [PLUGINS.md の「配布・更新・削除と、デバイスごとのオンオフ」](PLUGINS.md#配布更新削除とデバイスごとのオンオフ)）。

| 操作 | どうなるか |
|---|---|
| **[配布] → みんなに配布** | 全員の **設定 → 外観 → カスタムテーマ** に出る。**勝手に適用はされない**（各自が選ぶ） |
| **[配布] → 自分だけに配布** | 自分の一覧にだけ出る。自分のほかのデバイス（スマホを含む）でも選べる |
| **更新**（同じ `id` でもう一度 [配布]） | そのテーマを選んでいるデバイスでは、すぐに新しい CSS に入れ替わる |
| **削除** | 一覧から消える。選んでいたデバイスではテーマなしに戻る（選んだことは覚えていて、同じ `id` で配布し直せばまた適用される） |
| **選ぶ / 外す**（トグル） | **そのデバイスでだけ**切り替える（そのデバイスに保存）。オンにできるのは1つだけで、別のものをオンにすると前のものは外れる |

- 開発用フォルダに配布済みと同じ `id` のテーマがあれば、自分のデバイスでは開発中のほうを使います

## 注意点

- **JS は動きません**。`theme.css` だけです。動きのあるものが欲しければプラグインにしてください
- 画像やフォントを使うときは、`url(data:...)` で CSS に埋め込みます（ほかのファイルは配布できません。外のサイトの URL は、オフラインや Tailscale の外では読めません）
- Android のステータスバー・ナビゲーションバーの色は、テーマでは変わりません（ライト / ダークだけに合わせます）
- テーマを外すと元に戻るので、壊れた見た目になっても **設定 → 外観 → カスタムテーマ** のトグルをオフにすれば直ります。
  設定の画面が見えないほど壊れたときは、開発用フォルダからテーマのフォルダをどけてください（PC 版）
